## Быстро проверить интерфейс без платных API

Python 3.12, uv, Node.js 22.18 или новее.

```sh
cd rehearsal
uv sync --locked
npm --prefix frontend ci
uv run --locked python -m uvicorn backend.text_app.main:app --host 127.0.0.1 --port 8001 --workers 1
```

Во втором терминале, также из `rehearsal`:

```sh
npm --prefix frontend run dev
```

Открыть http://127.0.0.1:5174/. Без ключей доступен демонстрационный текстовый режим с заготовками. Для настоящих LLM-ответов, голоса и видео следуйте [инструкции запуска](rehearsal/README.md) и [настройке выбранных аватаров](rehearsal/docs/SELECTED_AVATARS.md).

Ключи заполняются только локально в `rehearsal/.env.local`. Файла с ключами, баз диалогов, записей пользователей и окружений Python/Node в передаче нет.
