# Журнал исследования и запусков

5 сентября 2026. Режим TASK2_AI. Исходный план записан в config.json до запуска. Тайм-бокс 90 минут. Проверяем новую русскую речь на CPU/Mac, не меняем Pipecat. Человеческая оценка основная, измерение производительности вспомогательное.

## Подготовка

1. Прочитаны инструкции проекта. Применены caveman и Human Writing для текста, corp-k8s для проверки собственного pod, Hugging Face CLI для загрузки публичной модели. Навык интерфейсных деталей использован для страницы сравнения. Подагенты не привлекались.
2. Независимая оценка: идея имеет исторические аналоги; главный риск в покрытии артикуляции и непрерывности движений, а не только в скорости поиска. Выбраны библиотека форм и маленькая нейросетевая дорисовка.
3. Проверены текущий Kubernetes-контекст, Teleport, namespace, доступ чтения, личный pod и StatefulSet. Доступ действовал, pod отсутствовал, StatefulSet имел replicas=0. Включение запрошено. Изменений кластера и GPU-запусков не было.
4. Уточнение лица и бюджета не получило ответа к завершению. Использованы публичный синтетический набор и демоматериал разработчика локально. Никакие пользовательские изображения/голос не отправлялись наружу.
5. Несколько серий веб-поиска, первичные страницы и код. Маршруты и полезные источники в sources.md.
6. Клонированы EMMA Skin (4e20e3d) и DH Live (4467e97) в отдельный временный каталог. Нужные материалы затем скопированы в игнорируемую `artifacts/private/05_baked_lipsync`.
7. Публичный экспорт myned-ai/wav2arkit_cpu загружен командой `hf download`. Первая команда с `--include '*.onnx' '*.data' ...` была разобрана CLI не так, как ожидалось: скачались внешние веса без графа. Граф отдельно получен по явному имени `wav2arkit_cpu.onnx`. Итоговый список файлов проверен без хеширования.

## Реальные команды эксперимента

Из корня проекта:

```sh
.venv/bin/python artifacts/runs/05_baked_lipsync/lab.py prepare
.venv/bin/python artifacts/runs/05_baked_lipsync/render_cpu.py
.venv/bin/python artifacts/runs/05_baked_lipsync/lab.py serve
.venv/bin/python -m unittest discover -v -s artifacts/runs/05_baked_lipsync -p test_lab.py
node artifacts/runs/05_baked_lipsync/browser_probe.mjs
```

Последняя команда запускалась с `LIPSYNC_PLAYWRIGHT`, указывающим на уже установленный в соседнем проекте пакет. Зависимости основного приложения не переустанавливались. `say -v Milena -r 175` и FFmpeg PCM16 16 kHz mono вызываются списком аргументов из Python, текст через stdin. Никакого shell для пользовательского текста.

## Результаты и исправления

- CPU-драйвер: три контрольные фразы, три прогретых повтора каждой; результаты в metrics.json. Калибровка по отдельной фразе. Обработка 1/2-секундных кусков вынесена в диагностическую проверку, не названа готовым потоком.
- CPU-композитинг: 186 кадров каждого из двух вариантов. PIL и libx264, без VideoToolbox/Metal. Файлы CPU MP4 созданы, метрики в render_metrics.json. Контактный лист визуально просмотрен.
- Первый браузерный прогон обнаружил 0 кадров DH Live после переключения. Причина: функция исходного примера завершает requestAnimationFrame-цикл при `isPaused`. Оболочка теперь запускает цикл снова при возобновлении. Добавлена обязательная проверка, что за наблюдение получено не менее 30 кадров.
- После исправления: DH Live около 25 кадров/с, renderer действительно Apple M3 Pro Metal. На снимке лицо и фон видны, логотип сохранён; отмечена зелёная кайма. У простого варианта тело неподвижно.
- Исправлена возможная гонка отмены при декодировании DH-аудио: идентификатор поколения и обнуление старого `onended`. Старое событие не должно очищать новое аудио.
- В браузере проверены обычная отмена всех режимов, отсутствие перезапуска через 300 мс, новое высказывание, отмена во время подготовки, экран 390 px. Нет JS-ошибок и внешних запросов в зафиксированном прогоне. Это не акустический тест VAD.
- Первая команда unit-тестов ошибочно использовала окружение родительской папки без ONNX Runtime. Повторный запуск из корня rehearsal с его `.venv` дал 5/5 за 1,50 с. Код модели из-за этой ошибки не менялся.
- Сервер лаборатории перезапущен после валидации Host/Origin и Content-Length. Остановлен только установленный через lsof собственный процесс порта 8896. Приложение 5175 и его сервер не перезапускались.
- После перезапуска HTTP-проверки: страница 200, POST с чужим Origin 403, пустой текст 400. Запросы не запускали синтез.
