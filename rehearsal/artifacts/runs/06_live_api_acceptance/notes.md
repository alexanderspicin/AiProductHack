# Подготовка живой проверки

2026-09-05. TASK2_AI. Цель: русский TTS, реалистичный видеоперсонаж и быстрые прерывания при сохранении Pipecat. Пользователь разрешил создание и локальное хранение ключей, небольшие расходы. Рабочий потолок платных проб 100 RUB; подписки/автопополнение не включать.

Read-only проверка авторизованных кабинетов: Inworld free credits $1.00, On-Demand TTS-2 $25/1M chars, TTS-2 Flash $15/1M chars; auto-reload off. Список Inworld API Keys пуст. Anam Free Plan: 0 из 30 минут использовано. Покупки и генерации не запускались, новых ключей пока нет.

Перед созданием постоянных API-ключей требуется подтверждение непосредственно в момент действия по правилам управления браузером, даже при первоначальном разрешении. Запрошено создание отдельных ключей Inworld/Anam с минимальными доступными правами, сохранение только в локальный .env.local. После подтверждения: до 3 минут Anam и короткие синтетические русские реплики Inworld, учёт фактического расхода, контроль остановки/синхронизации. Бесплатные минуты не гарантируют доступ к любому API-режиму; проверить до генерации.

Другие локальные изменения (05_baked_lipsync и worklog) обнаружены до начала работы и не изменялись.

## Выполнено после подтверждения

Финальная проверка кабинетов: Inworld по-прежнему отображает $1.00 и auto-reload off; Anam показывает 0/30 min. Эти округлённые/запаздывающие счётчики не подтверждают нулевой расход квоты. Факт: пополнений и списаний за покупку не было; выполнены один TTS-запрос и две короткие видеосессии. Окончательная тарификация может отобразиться позже.

Созданы rehearsal-ru-test ключи Inworld и Anam. Локальный .env.local имеет права 600 и исключён Git. Inworld: read Voices/Router; Anam: create session tokens, read Personas/Avatars/Sessions, остальные права отключены. Прямой запуск SDK потребовал sessions.write, поэтому права не расширяли: применили поддержанный обмен на временный session token.

Окружение эксперимента изолировано в artifacts/private/voice-test-env: Python 3.12, anam 0.11.0, aiortc 1.15.0, av 17.1.0, httpx 0.28.1. Основной Pipecat не изменён.

Команды: `uv venv artifacts/private/voice-test-env --python 3.12`; `uv pip install --python artifacts/private/voice-test-env/bin/python anam httpx python-dotenv`; затем этим Python выполнены scripts/probe_inworld_ru.py и scripts/probe_anam_ru.py.

Inworld: одна фраза 160 символов, Svetlana / inworld-tts-2, PCM 24k mono. Первый фрагмент 1088 мс, полная генерация 2627 мс, аудио 10.5 с, 15 timestamp-сообщений. Реально присутствуют phoneticDetails и visemeSymbol. Расчёт по кабинету $25/1M chars: $0.004 из бесплатных кредитов. Повторного TTS не было.

Anam Cara-4: две короткие подключённые сессии; в первой сломался диагностический MP4-рекордер (добавление потока после открытия контейнера), не сам API. Два отказа прямого запуска до этого не дали видеопотока. Вторая сессия: подключение 2046 мс, первое слышимое по RMS аудио через 577 мс после отправки готового PCM, 1152x768. После interrupt последний кадр с RMS>200 пришёл через 673 мс. Это серверный/сетевой приём PCM, НЕ задержка от микрофона и НЕ измерение браузерного воспроизведения. Цель 300 мс не подтверждена.

Тест: фраза целиком, повтор той же фразы и interrupt спустя секунду речи. Сессии закрываются контекстным менеджером; максимальная серверная длительность 50 с, локальный timeout 55 с. Вторая сессия заняла 21.27 с, ошибок коллектора нет.

Запись для человеческой оценки: artifacts/private/live-api/anam_ru_review.mp4. Видео и аудио записаны отдельно с RTP-временем и привязкой к первому приходу; итог смонтирован с относительным сдвигом около 6 мс. Первый MP4 имел ошибку абсолютного сдвига дорожки; для оценки использовать только *_review.mp4. Такая запись не заменяет инструментальное измерение липсинка на стороне клиента.

Локальная независимая проверка WAV: после ffmpeg ресэмплинга в 16k Whisper small распознал содержание с небольшим расхождением «ваши сомнения»/«ваше сомнение»; Smart Turn COMPLETE, 84 мс. Это не оценка естественности голоса. Синтетическая фраза, без пользовательских PII/биометрии.

Вывод: связка работает, качественный победитель пока не выбран. Для живой интеграции сохранить серверный Silero/Smart Turn, по старту речи немедленно глушить клиентский звук и очищать устаревшие кадры, параллельно отправлять Anam interrupt. Не ждать STT. Человеческая оценка русского губ/голоса и сквозное микрофонное прерывание остаются обязательными. Новые подписки, пополнения и автопополнение не оформлялись.
