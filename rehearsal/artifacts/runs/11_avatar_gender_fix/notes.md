# Род начальной реплики исправлен

При запуске с Даниилом или Татьяной приложение готовит первую реплику через текстовую LLM и сохраняет её в копии сценария внутри новой сессии. Чат, контекст текстового агента, контекст Pipecat и TTSSpeakFrame читают одну сохранённую строку. Исходник методиста не меняется. Старые сессии не переписываются: для проверки исправления нужна новая тренировка.

Один короткий запрос требуется для нового сочетания текста, исходного имени, персонажа и модели. Успешный результат кэшируется в памяти сервера, до 128 вариантов. При перезапуске кэш пропадает, но начатые сессии сохраняют свой текст. Ошибка API или отмена подготовки не создаёт частично начатую сессию. Автоповторов нет. Расход относится к операции text_opening и виден в статистике как «Подготовка первой реплики».

В режиме без выбранного аватара поведение прежнее. Для выбранных аватаров офлайн-деморежим использует нейтральные заготовки, поскольку в нём нет LLM для согласования произвольного текста.

## Проверки

Первый вариант промпта дал 5 правильных результатов из 6. Татьяна в сценарии feedback сохранила мужское «отправил». Результат не принят, исходные ответы сохранены в results.json. Общее ролевое указание заменено инструкцией редактору: явно задан новый говорящий, объяснено значение «я», добавлены примеры согласования и сохранения чужой цитаты.

Повтор тех же шести случаев: 6 из 6 точно совпали с заранее заданными ответами, results_v2.json. Проверены оба направления смены рода, имя говорящего, купил/купила, выбрал/выбрала, решил/решила, подписал/подписала, готов/готова, доволен/довольна. Род Анны, Олега и их прямой речи не изменён. Нейтральная реплика сохранена. Все шесть повторных запусков взяли готовый текст без API-запроса.

Подготовка в финальной пробе заняла 1,14–1,68 с, запуск из кэша 1–3 мс. Это маленькая локальная выборка, не p95. Всего две серии: 12 текстовых запросов, 5229 токенов, расчёт приложения $0.0016758. Стоимость не является банковским списанием; рублей без курса оплаты не подставляем. Голосовые и видео-API не вызывались.

108 серверных тестов прошли за 2,96 с. Проверены общая строка в UI/Agent/VoiceTraining, реальный обработчик on_client_ready с TTSSpeakFrame для обоих профилей и прежнего 3D, ошибки/отмена, отсутствие ключа/согласия, идемпотентность, смена ключа кэша, старые сессии, статистика. 21 интерфейсный тест и production-сборка прошли. Предупреждения старые: устаревающие API библиотек и большой отложенный модуль прежнего 3D.

Первые прогоны тестов нашли ошибки в новых тестовых данных (неполное имя старой модели и другой участник повторного запуска), затем незамоканную подготовку в прежнем тесте Cartesia. Исправлены тестовые фикстуры; реальные ключи в unit-тесты не передавались.

## Воспроизведение

Из корня репозитория, реальные текстовые вызовы только последней командой:

```bash
.venv/bin/python -m pytest -q
npm --prefix frontend test
npm --prefix frontend run build
PYTHONPATH=. .venv/bin/python artifacts/runs/11_avatar_gender_fix/probe.py --env .env.local --output artifacts/runs/11_avatar_gender_fix/results_repeat.json
```

Для пробы нужен уже разрешённый OPENAI_API_KEY. Скрипт использует отдельную временную базу, синтетические реплики и общий журнал стоимости; пользовательские сценарии и разговоры не меняет. Одна проба выполняет до шести запросов без автоматических повторов.

Локальный сервер обновлён той же командой запуска и на прежнем порту:

```bash
.venv/bin/python -m scripts.run_selected --openai-env ../avatar_trainer/.env.local --voice-env ../voice-avatar-lab/.env.local --enable-apis --seconds 180 --port 8003
```

Внешний интерфейс остаётся на 5176. Ключи не копировались, настройки методиста не менялись.

Ограничение: шесть удачных примеров не гарантируют безошибочную морфологию любого текста. Последующие ответы продолжают генерироваться LLM с правилом рода выбранного персонажа. Новых речевых или визуальных оценок в этой задаче не проводилось.
