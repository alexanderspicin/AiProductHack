# Полный предрасчёт графики

Статус: полный GPU/CPU-цикл реализован и проверен. Предыдущий run 05 не закрывал эту задачу: в нём не было собственного GPU-предрасчёта графики.

Независимая оценка: нужен отдельный формат подготовленного аватара и проигрыватель, который не умеет генерировать новые изображения. Нейросетевая модель допустима на этапе подготовки; во время разговора допустим небольшой аудиодрайвер и выбор графических состояний.

План: проверить доступный графический движок; подготовить библиотеку на H100; перенести файл на Mac; подобрать непрерывную последовательность для новых фраз; сравнить с прямым рендером на тех же движениях; проверить скорость, тишину и отмену. Основной Pipecat остаётся вне изменений.

Ресурсы: личный pod обнаружен Running, его владелец проверен, H100 свободна. На PVC 4,4 ГБ свободно, в /tmp около 506 ГБ. Новые промежуточные данные будут в отдельной временной папке. Масштабирование и чужие pod не используются.

Первое ограничение зависимостей: текущий DH Live требует epoch_40_new.pth, но публичная папка авторов содержит только старый epoch_40.pth. Нельзя подставлять несовместимые веса молча. Проверяем совместимый исторический код для воспроизводимого графического учителя.

Итог: совместимый код найден, веса загружены строго. H100 рассчитала 6400 библиотечных и 474 контрольных кадра за 13,36 с. Переносимая библиотека около 107 МБ. Отдельный CPU-процесс без PyTorch: до 24,1 мс на кадр в 95% случаев, около 183 МБ памяти. Браузер с отключённым GPU: 24,9 кадра/с. 9 unit-тестов и проверка нового текста/отмены/мобильного интерфейса успешны. Платных API-вызовов нет. Основной Pipecat не менялся.

На трёх новых фразах плавный выбор уменьшил ошибку межкадрового изменения относительно простого ближайшего состояния. Средняя покадровая ошибка области рта относительно прямого учителя 4,06–4,38 по шкале 0–255. Это ошибка аппроксимации, не оценка реализма и не точность фонем.

Решение keep для архитектурной гипотезы. Качество конечного персонажа inconclusive: нужны человеческая оценка, качественный голос, длинные записи поведения и эмоции. Ограничения и все команды в README.md / REPRODUCE.md. Предрасчёт закончен; GPU-процесс завершён, pod не масштабировался.
