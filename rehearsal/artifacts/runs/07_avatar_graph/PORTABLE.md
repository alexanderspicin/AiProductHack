# Подготовленный аватар: CPU-проигрыватель

Содержимое: готовые изображения тела и рта, параметры выбора движений, небольшая ONNX-модель управления ртом, CPU-код. Нейросетевой модели генерации изображений здесь нет.

Исследовательский пример DH Live, https://github.com/kleinlee/DH_live. Маркировку не удалять. Коммерческие права на внешность и модель отдельно не подтверждены; пакет не публиковать как очищенный коммерческий актив.

Установить Python 3.12 и ffmpeg. Распаковать архив в новую папку. Команды из папки, содержащей `package/`:

```sh
python3 -m venv cpu_env
cpu_env/bin/pip install -r package/requirements-cpu.txt
cpu_env/bin/python package/lab.py --root . --port 8897
```

Открыть http://127.0.0.1:8897. «Спокойное» включает замедленную голову, смешивание соседних поз и небольшое дыхание корпуса. «Исходное» служит сравнением. Прерывание останавливает звук, но не возвращает голову в начало.

Текстовый ввод озвучивает macOS Milena. Если системный голос недоступен, загрузить WAV: PCM16, моно/стерео, до 45 секунд, 8–96 кГц, до 10 МБ. Загрузка остаётся на localhost. В Linux и Windows можно проверять готовый WAV без `say`. Примеры доступны, если они были включены при упаковке.

Для контрольного MP4 без нового поведения головы/корпуса:

```sh
cpu_env/bin/python package/runtime.py --package package --wav new_phrase.wav --out result.mp4
```

`new_phrase.wav` для этой команды: моно PCM16. Интернет нужен для установки пакетов, после установки обработка локальная. GPU, PyTorch, исходники DH Live и API-ключи не нужны. Браузер может использовать обычное графическое ускорение Canvas; нейросетевой генерации изображений нет.

Размер библиотеки записан в `package/manifest.json`; в основном демо 100 поз и 64 состояния рта. Новые фразы поддерживаются через выбор готовых состояний; точность и эмоции ограничены библиотекой. Замеры подтверждают скорость на M3 Pro, а не на любом CPU. Подготовка графики не равна обучению нового персонажа. Это локальная лаборатория, не общедоступный сервер: не менять привязку 127.0.0.1 без отдельной защиты.
