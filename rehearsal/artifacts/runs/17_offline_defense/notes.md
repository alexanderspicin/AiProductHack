# Отдельное офлайн-демо для защиты

## Сохранение одного видео по просьбе пользователя

Первый пример «Клиент», Piper Дмитрий. `export_video.cjs` переиспользует WAV из локального кэша и тот же MotionRenderer с плавной головой/корпусом. Сохранён портрет без интерфейса, с подписью AI/DH Live. Команда: `node artifacts/runs/17_offline_defense/export_video.cjs`; NODE_PATH и CHROME_PATH задаются как для browser.cjs. Внешние запросы блокируются.

MP4: H.264 + AAC, 360 × 540, 25 кадров/с, видео 6,32 с, аудио 6,327 с, 372 180 байт. Экспорт 6,7 с; полный decode ffmpeg прошёл. Результат и исходные параметры в export_video.json; сам ролик в игнорируемой private-папке, копия в «Загрузках» пользователя под именем rehearsal-offline-example-1.mp4. Новых API-вызовов и генерации изображений нет. Это готовая запись для показа, не запись живого разговора с LLM.

7 сентября 2026. Режим TASK2_AI. Пользователь выбрал «Демо голоса и аватара + описание» вместо внедрения локальной LLM. Основной тренажёр на 5176, его БД, модели и ключи не менялись. Независимая оценка и бюджет времени записаны в worklog до реализации.

## Что сделано

- Стенд на 8898, отдельные `server.py`, `tts_worker.py`, HTML/CSS/JS. Три русские фразы, произвольный ввод, два голоса, остановка, счётчики, объяснение алгоритма.
- Переиспользованы локальные Driver, select_states, MotionClock, MotionRenderer и HTTP-range helper из run 07. Атлас 100 × 64 не пересчитывался. GPU не вызывался.
- Piper Дмитрий и Silero v5.5 Евгений работают на CPU из готовых весов. Старый macOS Milena не используется. Окружение TTS отделено от аудиодрайвера из-за различий зависимостей.
- Модели не скачиваются автоматически. TTS-процесс не получает ключи/прокси из окружения, Python socket.connect и getaddrinfo запрещены audit hook. Браузер ограничен self через CSP. HTTP только loopback; проверяются Host, Origin, тип и размер тела. Введённый текст не пишется в лог, синтезированный WAV сохраняется локально с ограничением числа файлов.
- Остановка выключает AudioBufferSource, сбрасывает рот и номер текущего ответа. Поздний результат игнорируется. Уже запущенный расчёт TTS может завершиться в фоне; максимум 45 с. Это явно написано в интерфейсе и README.
- Инструкции: docs/OFFLINE_DEFENSE.md и demos/offline/README.md. Разделены реализованное, прошлые результаты, проектируемые части и лицензии.

## Команды

Из корня rehearsal, ранее подготовленные локальные окружения:

```sh
artifacts/private/07_avatar_graph/cpu_env/bin/python demos/offline/server.py
artifacts/private/07_avatar_graph/cpu_env/bin/python artifacts/runs/17_offline_defense/probe.py
node artifacts/runs/17_offline_defense/browser.cjs
artifacts/private/07_avatar_graph/cpu_env/bin/python -m compileall -q demos/offline artifacts/runs/17_offline_defense/probe.py
node --check demos/offline/player.js
git diff --check -- demos/offline artifacts/runs/17_offline_defense docs/OFFLINE_DEFENSE.md artifacts/worklog.md
```

Для browser.cjs использованы комплектные библиотеки Playwright через NODE_PATH и установленный Chrome через CHROME_PATH. Первый запуск headless Chrome в песочнице завершился SIGABRT/EPERM. Повтор вне песочницы успешен, отдельный временный профиль; пользовательский профиль не трогали. Команда sysctl для уточнения чипа получила Operation not permitted; не используем это как измерение конфигурации. Ранее проект проверялся на M3 Pro, текущие результаты обозначены просто как текущий Mac.

TTS: piper-tts 1.7.0, torch 2.13.0, onnxruntime 1.29.0, numpy 2.5.2. Аудиодрайвер использует существующее CPU-окружение run 07. Веса уже были на диске, новые установки не выполнялись. `du -sh` пакета: 102M в единицах утилиты; историческое измерение около 107 МБ десятичных. Не смешиваем их в оценке роста.

## Результаты

`metrics.json`: шесть синтезов, три текста × два голоса, все без кэша. Моно PCM16, ненулевая энергия, разные состояния рта. Piper: 0,803–1,304 с на всю подготовку, аудио 5,15–6,33 с. Silero: 1,612–2,107 с, аудио 5,39–6,79 с. Анализ аудио: 6,9–14,4 мс. Это отдельные короткие вызовы, не распределение нагрузки, не p95 и не потоковый первый звук.

HTTP: пустой/слишком длинный текст и неизвестный голос отклонены; чужой Origin отклонён; `.env`, обход путей и чужой файл недоступны; повтор возвращается как кэш. Python и JavaScript проходят синтаксическую проверку.

`browser.json`: реальное декодирование и запуск обоих WAV в WebAudio, остановка с нейтральным ртом, игнорирование задержанного ответа, новый текст без кэша, режим уменьшенного движения. Пять ширин от 320 до 1360 px без горизонтального переполнения. Ошибок JavaScript и попыток внешних запросов нет. Браузер с `--disable-gpu`: для этого интерфейса нейросетевая генерация изображения на GPU не требуется.

Снимки desktop.png, mobile.png, speaking-piper.png, speaking-silero.png просмотрены. Нейтральное состояние модели не означает идеально сомкнутые губы: исправлена слишком сильная формулировка в интерфейсе. При ручном анализе кода найдена ошибка пустого ввода во время речи: статус мог стать «готов», а звук продолжал играть. Исправлена остановкой перед проверкой текста, добавлена браузерная регрессия.

Скорость JavaScript-обработчика stop не выдаём за время акустического прерывания. Скриншоты не доказывают синхронизацию русских фонем. Воспроизведение тестировалось программно; естественность и воспринимаемый липсинк должен оценить человек.

## Решение

keep: функциональная автономная мультимедийная демонстрация. Качество русского липсинка: inconclusive до человеческого просмотра. Полный автономный разговор не реализовывался по согласованному объёму. Внешние API: 0 вызовов, 0 ₽. Предрасчёт GPU: 0 запусков. Публикации, передачи весов и замены рабочего продукта не было.
