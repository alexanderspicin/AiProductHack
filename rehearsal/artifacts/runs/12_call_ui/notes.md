# Экран тренировки, 6 сентября

Решение: keep. Видео стало основной частью экрана, переписка и ввод больше не раздвигают страницу. Один запуск подключает разговор; микрофон и текст доступны независимо. Серверный Pipecat, пары персонажей, сценарии и отчёты сохранены.

## Независимая оценка

Причина по исходникам: `.selected-voice` находился в старой сетке `.chat-panel.has-avatar`, но не имел размещения, заданного для прежнего `.voice-tools`. Браузер создавал дополнительную строку. Блок видео и управления вытеснял ввод. Уменьшение видео само по себе проблему не решало.

## Проверки и команды

Из корня репозитория:

```bash
npm --prefix frontend test -- --run
npm --prefix frontend run build
.venv/bin/python -m pytest -q
git diff --check
```

Для браузерной проверки нужны Playwright, Chrome и фронтенд на 5176:

```bash
node artifacts/runs/12_call_ui/browser.cjs
```

При необходимости NODE_PATH задаёт каталог модулей Playwright, CHROME_PATH путь к браузеру. Здесь использованы комплектные зависимости среды и изолированный headless Chrome. API перехвачены; внешние адреса заблокированы. История вымышленная: 35 пар реплик. Личная сессия пользователя не изменялась.

- 30 тестов интерфейса в 10 файлах, 1,16 с. Новые: запуск, отказ микрофона, отмена подключения, позднее разрешение, переключение микрофона, отправка текста без второго движка, ожидание очистки перед отчётом, сохранение черновика.
- 108 тестов сервера, 3,42 с. 24 предупреждения устаревания зависимостей, ошибок нет.
- Сборка прошла, 1,54 с. Существующее предупреждение о крупном блоке старого 3D-режима осталось.
- Видеорежим: 8/8 размеров. Текстовый: 2/2. Ввод внутри окна, длинная история прокручивается отдельно, задача и параметры закрываются, кнопка разбора доступна.
- На 1440 × 900 область видео 1034 × 705,6 px, чат шириной 380 px. На 390 × 844 ввод заканчивается на 836 px; документ высотой ровно 844 px.
- 0 ошибок JavaScript, 0 неожиданных записывающих запросов, 0 внешних запросов в браузерной проверке. Расход API 0 ₽.
- Фронтенд 5176 и сервер 8003 отвечают HTTP 200.

Полные измерения: `browser.json`. Скриншоты: `call-*.png`, `text-*.png`. Они показывают макет до подключения, не новое сгенерированное видео.

## Ошибки по ходу

1. Первый тест менеджера подменял методы свойствами и затенял наследование. Исправлена подмена, повтор прошёл.
2. Песочница macOS не запускала Chrome; браузер и тесты MLX запущены вне песочницы в отдельных процессах.
3. Проверка переносила открытое меню на следующий размер окна. Добавлены закрытие в проверке и Escape/нажатие вне меню в интерфейсе.
4. На телефоне кнопка параметров переносилась, метка ИИ пересекалась с именем. Исправлены размеры и расположение.
5. При 320 × 360 меню выходило за верх окна на 3,2 px. Ограничена высота; повторная серия 8/8.
6. Очистка нового теста снимала подмену fetch до отложенной отмены: два обращения к несуществующему локальному порту 3000. Теперь очистка ждёт микрозадачи; финальный прогон без этих ошибок.

## Ограничения

В этой серии не использованы реальный микрофон, голоса и видеоквоты. События SDK проверены подменами и сверены с установленным исходным кодом; полный живой разговор с новым управлением должен проверить человек. Точность губ и сквозная задержка не измерялись. Уменьшенная высота окна моделирует место под экранную клавиатуру, но не заменяет настоящий iPhone. Предыдущие замеры медиа сохранены в run 09.
