## Результат

Подтверждены LiveAvatar Essential $99/1100 кредитов, LITE 1 кредит/мин, максимум 20 минут и overage $0,095. Inworld On-Demand TTS-2 $25/млн символов, Flash $15/млн. Официальный сайт Inworld явно указывает commercial license у On-Demand; никаких промокредитов в экономике. По сравнению с Tavus + Cartesia получены 14 928 ₽ для LiveAvatar + Cartesia и 10 965,50 ₽ для LiveAvatar + Inworld TTS-2, при 100 ₽/$.

Simli: curl главной страницы с `--max-time 20` вернул неполный HTML и ошибку 56; чтение указанного в HTML публичного JS нашло только ссылку на pricing без платных ставок. Вкладка каталога загрузилась и показала меню Billing, но отдельная тарифная страница не загрузилась. Резервные неопределённые цены не добавлены. Cartesia $65/млн сверх Pro найдены только на сторонних сайтах; их не используем как подтверждённый тариф.

Команда расчёта из корня rehearsal: `.venv/bin/python artifacts/calculations/calculate_cheaper_api.py`. Сохранены 15 сочетаний: 5 вариантов для 5/10/15 минут. Все пять assert прошли: прежний базовый итог 39 803, два новых итога, допустимый тариф для 10 минут, разница при смене только TTS. Независимая проверка основной суммы: 9900 + 937,50 + 128 = 10 965,50 ₽. Широких генераций и замеров задержки не было.

Вывод: keep как экономический вариант для пилота, не как доказательство одинакового качества. Сначала LiveAvatar + Cartesia, затем при необходимости Inworld. Прежний пользовательский отзыв не подтверждает качество Flash. Полная себестоимость с сервером, транспортом и методистом не посчитана; GPU-переход не объявлен необходимым.
