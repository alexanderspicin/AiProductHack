# Два выбранных персонажа в тренажёре

Режим TASK2_AI. Пользователь выбрал №1 Cartesia Sergei + Tavus Daniel и №5 Cartesia Tatiana + Anam Cara. Переключатель нужен методисту. Альтернативы разрешены при неприемлемой задержке, обязательность прежнего движка снята.

## План

1. Сохранить текущее поведение и проверить существующие тесты. Внешние API на этом шаге не вызываются.
2. Добавить серверные профили и настройку методиста с фиксацией в новой тренировке. Старые сессии не мигрировать на другой голос молча.
3. Подключить потоковый Cartesia и WebRTC-видео Tavus/Anam. Сценарий, серверные Silero/Smart Turn, локальное ASR и отчёт оставить общими.
4. Проверить прерывание по началу речи, запрет поздних пакетов, очистку соединений и возврат к тексту.
5. Проверить бесплатные квоты, выполнить ограниченные русские пробы, записать задержки. Если критерий скорости не выполнен, показать явный резерв без удалённого видео.
6. Проверить интерфейс методиста, полный учебный сценарий и разбор; обновить запуск и ограничения.

Текущие несвязанные изменения в artifacts и прежние лаборатории сохраняются. Никакой публикации, изменения тарифа или создания собственных лиц. Ключи берутся из существующих локальных конфигураций и не включаются в Git.

Superpowers в доступных навыках не найден. Используем последовательность: требования, план, тесты критичных контрактов, реализация, проверка. Навыки make-interfaces-feel-better и human-writing применяются к элементам выбора, состояниям соединения и документации. Sites-хостинг не применяется: это существующий локальный Python/ML-тренажёр без .openai/hosting.json, перенос в другой хостинг не запрошен.

## Живые результаты

Проба Tavus 1: приветствие и видео 1280×720 работали. Ручная остановка немедленно дала video.muted=true, paused=true. Новая реплика упала из-за отсутствия NLTK punkt_tab, а встроенная загрузка NLTK была запрещена его защитой от прокси. Установлен фиксированный официальный пакет через curl/unzip; добавлен проверяемый preflight. Исключение не выдано за проблему русского TTS.

Проба Anam 1: видео 1152×768, подключение 2038 мс, новая русская реплика, ответ сохранён, этап перешёл по цитате. От отправки текста до ненулевого аудио в удалённом потоке 4341 мс. Ручное mute/pause и закрытие проверены.

Проба Tavus 2: видео подключилось за 5044 мс. Три новых текста, ответы через Cartesia и Tavus. После ручного stop следующий ответ продолжил разговор. Задержки 4095, 5322, 5063 мс. На 90-секундном ограничении вывод закрылся; история сохранилась. Из трёх реплик сформирован LLM-отчёт по пяти критериям, цитаты видны в UI. Балл не использован как доказательство качества продукта.

Обнаружено копирование моделью первых реплик следующих этапов, в том числе женского рода у мужского персонажа. Из контекста агента и результата advance_stage удалены готовые opening_line, оставлены цели этапов и факты. Начальная реплика редактора остаётся дословной; UI предупреждает методиста проверить её род и имя. Снимок новой сессии получает имя выбранного профиля, исходный сценарий не изменяется. Проверка после исправления: новый вопрос о причинах провала прошлой платформы получил динамический ответ с признанием неизвестной причины за 1873 мс в текстовом резерве, не строку следующего этапа.

Синтетический WebSocket: существующий Inworld WAV, 16 кГц, первые 8 с, затем 4 с тишины, без микрофона и без видеосервиса. Серверный user-started-speaking и avatar_interrupt пришли через 580 мс от первого входного пакета, первая транскрипция ещё через 1310 мс. После последнего user-stopped-speaking новый PCM появился за 1374 мс. Это скорость выдачи PCM, не фактического звука динамика. Последняя реплика в пробе намеренно обрезана закрытием после двух секунд нового ответа; interrupted сохранён.

Whisper на полном синтетическом WAV: 1852 мс на распознавание, текст по смыслу корректен. Smart Turn вернул COMPLETE за 39 мс. На потоковой записи были промежуточные окончания хода; устойчивость к паузам в живой русской речи ещё должна оцениваться человеком.

Дополнительное локальное сравнение трёх VAD-настроек не использовало API. Переход .7/.1/.6 к .55/.08/.6 и .5/.08/.45 сократил первый SPEAKING с 608 до 576/544 мс. На тишине и тихом синтетическом шуме ложных стартов не было. Решение reject: выигрыш 32–64 мс недостаточен для изменения чувствительности по одному голосу; реальные шумы не проверены. Оставлена исходная выбранная настройка .7/.1/.6.

## Решение и границы

Keep: две пары внутри полноценного сценария, явный голосовой резерв без видео, сохранённый текст и разбор. При ответе дольше 2,5 с UI предлагает сравнить резерв; автоматической замены лица нет. Target ответа видео <=2500 мс не достигнут. Target физического микрофона <=300 мс не доказан. Нельзя выдавать 0–1 мс JavaScript mute за полную задержку микрофона.

Бесплатные кабинеты после проб: Cartesia 18702 кредита (до 19680), Tavus 3,3/20 минуты (до 1,5), Anam 2/30 (до 1). Числа интерфейсов могут округляться и обновляться с задержкой. Покупок и подписок нет. Статистика текста в существующей базе: 17766 токенов, расчёт $0.00359751 по измеренным запросам; это включает прежнюю активность и не является точным счётом этой задачи. Три запроса без полного usage отмечены отдельно.

## Команды воспроизведения

```bash
uv sync --locked --extra voice
uv lock --cache-dir /tmp/rehearsal-uv-cache
npm --prefix frontend ci
uv run --locked --extra voice python -m scripts.check_voice --whisper
uv run --locked --extra voice python -m scripts.check_voice --audio artifacts/private/live-api/inworld_ru_16k.wav --fast --whisper
uv run --locked --extra voice python -m scripts.probe_vad_tuning --audio artifacts/private/live-api/inworld_ru_16k.wav --output artifacts/runs/09_selected_live_avatars/vad_tuning.json
uv run --locked --extra voice python -m scripts.probe_selected_voice --audio artifacts/private/live-api/inworld_ru_16k.wav --output artifacts/runs/09_selected_live_avatars/synthetic_vad_probe.json
uv run --locked --extra voice pytest -q
npm --prefix frontend test
npm --prefix frontend run build
```

Последняя команда probe_selected_voice вызывает Cartesia и настроенный текстовый API: запускайте только при проверенной квоте. Исходный синтетический WAV не включён в Git; можно передать свой синтетический PCM16 mono WAV. Скрипт не записывает микрофон и не читает ключи. Для локальной сессии использовались backend 8003 и Vite 5176. Переносимый запуск с собственными ключами описан в docs/SELECTED_AVATARS.md.

## Проверка интерфейса

| До | После | Проверка |
| --- | --- | --- |
| Один технический 3D-режим в админке | Две человеческие пары в кабинете методиста | Обе выбраны и сохранены через реальный UI |
| Технологии смешаны с действиями участника | Участнику показаны разговор, видео с текстом, стоп и отключение | Просмотр DOM и скриншота |

| Метрики только технические | Подписи отделяют выдачу PCM, звук видео и JavaScript-команду mute | Проверка смыслов и сохранённого JSON |

Навык make-interfaces-feel-better использован для крупных выбранных карточек, фокуса, размеров кнопок и состояний. Визуально проверен кабинет методиста при ширине 1280; отдельный мобильный браузер не проверен. Естественность губ по новым произвольным диалогам остаётся человеческой приёмкой.

Простой duplicate-stop и отмена до prepare тоже покрыты тестами.

Финальный серверный прогон: 91 тест, 0 ошибок, 2,53 с. Frontend: 20 тестов, сборка прошла. Сохранилось предупреждение сборки о большом legacy-3D чанке, который загружается отдельно. Серверные deprecation warnings Pipecat/FastAPI не скрыты. `git diff --check` без ошибок. Поиск типовых секретов и абсолютных домашних путей в новых файлах и документах совпадений не дал; старые несвязанные артефакты не переписывались. Коммит и публикация в Git не выполнялись. Финальный сервер оставлен с ограничением 180 с на подключение; новые API-разговоры автоматически не запускаются.
