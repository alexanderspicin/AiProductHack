# Восстановление согласованной архитектуры

Финальный прогон: 81 серверный тест, 15 фронтенд-тестов, production-сборка успешна. Добавлены проверки текстового ввода внутри Pipecat и часов PCM: субтитры и виземы не показываются до звука, отменённые события отбрасываются. Сквозные цели задержки и пять голосовых диалогов пока не измерены без Inworld. При подготовке журнала неудачная автоматизация патча временно повредила две строки; восстановлены до повторной сборки.

Прежний результат был ошибочным по архитектуре: вместо подключения UI к Pipecat появился собственный голосовой движок. Этот вариант заменён исходным бэкендом команды.

Команды:

```bash
uv sync --locked --extra voice
npm --prefix frontend ci
uv run --locked --extra voice pytest -q
npm --prefix frontend test
npm --prefix frontend run build
uv run --locked --extra voice python -m scripts.check_voice --audio sample.wav --whisper
```

Контрольный sample.wav: локальный русский системный голос, «Добрый день. Давайте обсудим вашу задачу.», PCM16 mono 16 кГц. Запись длиной 2,99 с. Локальное распознавание прошло точно; Smart Turn ответил INCOMPLETE, резервные таймауты сохранены как в исходнике команды.

Один платный контрольный запрос OpenAI сделан командой `python -m scripts.check_llm`. 32 токена, первый текст через 3,79 с. Доступ к модели подтверждён, малая задержка всего диалога не доказана. Inworld не вызывался.

Найденные при проверке ошибки:

- На Apple Silicon модуль Whisper Pipecat требует mlx-whisper даже при использовании faster-whisper. Добавлена зависимость для macOS.
- Остановка ожидала общий ASGI-task и зависала в WebSocket-тесте. Pipecat перенесён в отдельную задачу, stop ждёт её завершения, сокет закрывается явно.
- Старые виземы после interrupt могли снова открыть рот. Добавлено отбрасывание и тест переподключения.
- Старые локальные VAD-ассеты оставались в public и попадали в сборку. Они убраны из public и зависимостей; резервная копия вне репозитория.

Решение: сохранить интеграцию. Перед защитой обязательна ручная проверка команды с Inworld: паузы, перебивание, русские виземы и отчёт. Автотесты подменяют платные генераторы и не заменяют эту приёмку.
