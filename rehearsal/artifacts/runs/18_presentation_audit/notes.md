# Проверка презентации и план правок

Дата 07.09.2026, TASK2_PRODUCT. Первоначальный объём: read-only аудит 13 слайдов, видео, кейса и памятки. Затем пользователь уточнил порядок: CPU-демо, основной API-путь, стоимость бизнеса и альтернатива GPU. План расширен расчётом, изменения исходного PPTX и продукта не запрашивались и не выполнялись.

## Решения и результаты

- Изучены все 13 слайдов, заметки и одна страница критериев; изображения всех слайдов просмотрены. Встроенный ролик проверен по 20-секундным срезам, не прослушан как непрерывная акустическая запись. PowerPoint-воспроизведение не проверялось.
- Главная архитектура: Pipecat + локальные Silero/Smart Turn/faster-whisper + OpenAI + Cartesia + Anam/Tavus. Слайды описывали прежний Inworld/Three.js.
- Накопленная числовая телеметрия собрана без текстов пользователей, имён, секретов и идентификаторов сессий. `current.json`: Anam n=9, медиана 2199 мс; Tavus n=18, медиана 3458 мс. Это смешанные исторические сессии, не новый контролируемый тест.
- Два теста реального UI-компонента с имитацией позднего TTS-текста подтвердили отсутствие защиты субтитров поколением. Passing означает воспроизведение дефекта, не корректность отмены. Аудио отдельно защищено поколениями. Живой SDK и физический микрофон в этой задаче не вызывались.
- В коде автоматическое завершение по числу реплик не запускает отчёт; явное пользовательское завершение запускает. Отмечено как пункт проверки/правки, не изменено.
- Проверены внешние проценты и кейсы: +2% найдено в авторском SSRN-исследовании; у «Зетты» метрика относится к тренировочным звонкам. Неподтверждённые проценты не названы ложными, рекомендовано убрать до первоисточника.
- Основной отчёт: `docs/PRESENTATION_AUDIT.md`. Точечные правки и экономика: `docs/SLIDE_EDITS_AND_COSTS.md`.

## Команды

Из корня репозитория. Python для PDF: bundled runtime с pypdf. Для остального существующая `.venv`. Исходные файлы передаются пользователем; в Git не копируются.

```sh
python artifacts/runs/18_presentation_audit/inspect_sources.py --deck '<PPTX>' --criteria '<PDF критериев>' --out artifacts/private/18_presentation_audit
soffice -env:UserInstallation=file:///private/tmp/rehearsal-slide-review-20260907 --headless --convert-to pdf --outdir artifacts/private/18_presentation_audit '<PPTX>'
python artifacts/runs/18_presentation_audit/extract_video.py '<PPTX>' artifacts/private/18_presentation_audit/slide12.mp4
ffprobe -v error -show_entries format=duration,size:stream=index,codec_type,codec_name,width,height,r_frame_rate -of json artifacts/private/18_presentation_audit/slide12.mp4
ffmpeg -hide_banner -loglevel error -i artifacts/private/18_presentation_audit/slide12.mp4 -vf 'fps=1/20,scale=720:-1,tile=3x5' -frames:v 1 artifacts/private/18_presentation_audit/video-contact.png
node frontend/node_modules/vitest/vitest.mjs run --config artifacts/runs/18_presentation_audit/vitest.config.ts
.venv/bin/python artifacts/runs/18_presentation_audit/collect_current.py --db artifacts/text_workspace.sqlite3 --out artifacts/runs/18_presentation_audit/current.json
.venv/bin/python artifacts/calculations/calculate_defense_costs.py
```

Рендер PDF выполнялся только scratch-копией с bundled LibreOffice; оригинал не сохранялся заново. Fontconfig предупредил о недоступном кэше; PDF и 13 изображений сформированы.

В начале диагностический Vitest не стартовал: сначала неправильный root/config, затем bundled plugin-react тянул недоступный `vite/internal`, затем импорт mocks не распознавался и попадал в CommonJS. Исправлена только отдельная конфигурация аудита: esbuild JSX automatic, прямой ESM alias Vitest. Финал: 1 файл, 2 теста прошли за 632 мс, тестовые тела 40 мс. Полный тестовый набор продукта заново не запускался.
