# Уточнение и улучшение аватара

Независимая оценка: итоговый MP4 содержит корректные кадры и звук по ffprobe/ffmpeg, но нативный плеер внутри Codex показывает чёрный экран. Нужна проверка именно в нём, а не только декодирование файла. Сервер также не поддерживал Range и HEAD.

Дрожание: один 25fps-счётчик перебирает позы и в речи, и в тишине; на концах путь сразу разворачивается. Замедление аудио не подходит: нужно отдельное время поведения, мягкое изменение скорости и интерполяция поз.

Вход текущего предрасчёта: подготовленный видеопакет DH Live. Одна фотография сама по себе не содержит движений рук и тела. Не выдавать существующий видеопакет за результат новой генерации из фото.

План: совместимый плеер; спокойная голова и малые движения корпуса; последовательный CLI; проверки без платных API; короткая инструкция с источниками.

## Результат

Решение `keep` для локальной проверки. Во встроенном браузере сравнительный ролик показывает три лица и доигрывает до конца. Добавлены WebM/Opus, HTML-плеер, постер, Range и HEAD. Старый адрес comparison.mp4 при открытии как страницы переводит в плеер, скачивание исходного MP4 остаётся доступным. Корректность отдельных изменений контейнера и HTTP не изолировали: точную единственную причину чёрного экрана не объявляем.

| До | После |
|---|---|
| Один темп головы в речи и тишине | Отдельные часы: спокойный темп 0,22, при речи 0,42; рот по аудио |
| Мгновенный разворот перебора поз | Косинусный разворот и смешивание двух соседних поз |
| Небольшое дрожание области лица | Сглаженная поправка положения до 3 пикселей для целого кадра с уже наложенным ртом |
| Неподвижный корпус | Малое дыхание и покачивание, без новых жестов рук |
| Только системный голос | Дополнительно PCM16 WAV от другого TTS, локальная обработка |
| Только команды разрозненных этапов | workflow.py, инструкция, переносимый архив с интерфейсом |

Навык проверки интерфейсов повлиял на решение: тестировался именно пользовательский встроенный браузер, добавлены явные состояния проигрывателя и переключение «исходное / спокойное». Просмотр Canvas проверен визуально. Новый вид не назван неотличимым от человека.

## Проверки

- 9 прежних тестов выбора состояний и отмены: прошли.
- 6 новых тестов HTTP Range: прошли.
- Тест траектории головы, ограниченного возврата после скрытия вкладки, одной позы и отключения тела: прошёл. Вторая разность индекса позы уменьшилась; это не измерение физического ускорения головы.
- HTTP: HEAD, Range MP4/WebM, 416, старый адрес, запрет постороннего Origin, запрет обхода путей, неправильный WAV, PCM16 mono/stereo, ограничение длительности: прошли.
- Системный голос: подтверждён ненулевой звук, а не только успешный HTTP-код.
- Фактический интерфейс: около 30 кадров/с в тишине и речи, смена поведения, отключение тела, остановка активной 33,5-секундной фразы, нейтральный рот после остановки, загрузка WAV через выбор файла. Загрузка 6,3-секундного WAV подготовлена за 0,08 с в одном наблюдении.
- Четыре WebM полностью декодированы ffmpeg без ошибок. Сравнение визуально проиграно во встроенном браузере.
- Свежая мини-сборка 4 × 8: подготовка, экспорт для GPU, офлайн-расчёт на CPU, импорт с build_id, новая фраза, упаковка. 32 изображения библиотеки + 474 контрольных кадра. Это техническая проверка, не финальное качество восьми состояний.
- Полный переносимый пакет распакован во временную папку. CPU-скрипт из пакета собрал 145 кадров с новым WAV; видео 5,80 с, сборка с кодированием 1,73 с. В изолированном окружении нет torch/OpenCV. Архив 108302032 байта.
- Python compileall и git diff --check: прошли. Байтовых сравнений или хешей не выполнялось.

Числа: [HTTP](http_metrics.json), [движение](motion_metrics.json), [браузер](browser_metrics.json), [повторная сборка](rebuild_metrics.json), [пакет](package_metrics.json).

## Найденные ошибки и исправления

1. Системный `say` внутри песочницы возвращал пустую речь без ненулевого exit code. Первый свежий набор имел только тишину. Это не принято за успешную калибровку. Добавлена проверка ненулевой речи; локальная лаборатория перезапущена с разрешённым доступом к голосу macOS. Повторная подготовка использовала сохранённые PCM16 записи через `--audio-dir`.
2. Офлайн Chromium не стартовал внутри песочницы из-за запрета MachPort. Только этап растеризации запущен с расширенным разрешением, на локальных данных. Пользовательский интерфейс проверялся отдельно через CUA.
3. В upstream AdaAT CPU-ветка фиксирует batch=1. Первый CPU-предрасчёт с batch=8 упал. Исправлен размер пакета для CPU; повторный полный маленький расчёт прошёл.
4. Личный GPU проверен read-only: StatefulSet существует, replicas=0, pod отсутствует. Число реплик не менялось, GPU в этой доработке не использован. Вместо него проверена маленькая CPU-сборка.

## Что ещё не доказано

Новое лицо из фотографии; свежая установка всех зависимостей и повторная загрузка весов; более качественный TTS в контролируемом сравнении; человеческая точность русских смыканий; низкая задержка потокового разговора; акустическая задержка остановки. Ролики сравнения содержат исходное движение run07. Новая спокойная голова и корпус проверяются в интерактивном интерфейсе; контрольный runtime.py намеренно оставлен прежним.

Следующий узкий эксперимент: одна фраза, два голоса, одна библиотека. Пользователь отдельно оценивает звук, попадание смыканий и общий комфорт. При смене голоса не менять одновременно число состояний и поведение головы. Если проблема сохраняется в прямом учителе, увеличение атласа не считается решением.
