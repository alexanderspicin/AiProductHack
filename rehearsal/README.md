# Репетиция

Передача команде от 7 сентября: [начать здесь](../FINAL_VERSION.md). Все команды ниже выполнять из папки `rehearsal/`. Старый проект команды находится в корне и сохранён отдельно.

Тренажёр корпоративных разговоров: сценарии методиста, диалог с ИИ-персонажем, стенограмма и предварительный отчёт с цитатами.

Два выбранных пользователем варианта:

| Персонаж | Голос | Живое видео |
| --- | --- | --- |
| Даниил | Cartesia Sergei | Tavus Daniel |
| Татьяна | Cartesia Tatiana | Anam Cara |

Методист выбирает вариант в разделе «Персонаж тренировки». Настройка действует для новых сессий. Имя и внешний вид меняются, роль и факты сценария сохраняются. При задержке видео можно явно перейти к тому же голосу без видео или к переписке.

## Запуск

Нужны Python 3.12, uv, Node.js 22 и npm. Все команды из корня репозитория.

```bash
uv sync --locked --extra voice
npm --prefix frontend ci
cp .env.example .env.local
uv run --locked --extra voice python -m nltk.downloader -d models/nltk_data punkt_tab
```

В `.env.local` заполните `OPENAI_API_KEY`, `CARTESIA_API_KEY`, `TAVUS_API_KEY` и `ANAM_API_KEY`. Ключи только на сервере, не в браузере и не в Git. Для CPU оставьте Whisper cpu/int8.

```bash
uv run --locked --extra voice python -m scripts.check_voice --whisper
uv run --locked --extra voice python -m scripts.run_selected --enable-apis
```

В другом терминале:

```bash
npm --prefix frontend run dev
```

Откройте [тренажёр](http://127.0.0.1:5174/). Флаг `--enable-apis` разрешает вызовы уже настроенных сервисов; сам запуск не начинает разговор и не покупает тариф. Если загрузка NLTK недоступна через прокси, альтернативная установка описана в [инструкции](docs/SELECTED_AVATARS.md).

## Как проверить

Перед стартом показана общая ситуация и роли. Краткий план остаётся над разговором; в новых сессиях OpenAI пункты можно обсуждать не по порядку. Персонаж отстаивает собственную позицию, подсказки и оценка вынесены из его речи. Поля методиста, примеры и ограничения: [логика тренировки](docs/ROLEPLAY.md).

1. «Открыть как: Методист». Создайте и опубликуйте сценарий либо выберите готовый.
2. «Персонаж тренировки». Выберите Даниила или Татьяну, сохраните.
3. «Открыть как: Участник». Начните новую тренировку с вымышленными данными.
4. Нажмите «Начать диалог». Персонаж произнесёт первую фразу. Дальше говорите или пишите в чат. Кнопка микрофона выключает и включает ваш звук; камера не нужна. Если доступ к микрофону запрещён, видео и переписка остаются доступны.
5. Перебейте персонажа голосом, новым сообщением или кнопкой «Перебить». Проверьте, что старый ответ не возвращается и новый учитывает сказанное.
6. «Завершить», затем «Получить разбор» создаёт отчёт. Чтобы лишь прерваться, выберите «Ещё», «Приостановить диалог»: подключение закроется, история сохранится.
7. Методист проверяет цитаты, дополняет разбор. Администратор отдельно настраивает модель и видит расход текстовых токенов.

Начатая тренировка сохраняет выбранный голос. Для сравнения другого персонажа нужна новая сессия.

На компьютере видео занимает основную часть окна, чат расположен справа. На телефоне чат под видео. Поле ввода остаётся в пределах экрана, прокручивается только переписка. Задача и этапы открываются кнопкой «Задание», параметры соединения спрятаны в «Ещё».

Для Даниила и Татьяны начальная реплика согласуется по имени и роду до запуска сессии. Подготовленный текст общий для чата, истории модели и озвучки. Один короткий текстовый запрос на новый вариант реплики учитывается в статистике; повторные запуски используют кэш сервера, пока он не перезапущен (до 128 вариантов). При ошибке API тренировка не начинается. Исходный сценарий и старые сессии не переписываются. В офлайн-деморежиме выбранные аватары используют нейтральные заготовки.

## Что работает

Общий серверный Pipecat: Silero VAD, Smart Turn v3, локальный faster-whisper, OpenAI, потоковый Cartesia. Аудио передаётся выбранному аватару частями, не готовым видеороликом. Во время разговора ответы генерируются на новый текст. Примеры стартовых реплик этапов не передаются модели как готовые ответы.

Браузер получает синхронные звук и изображение одним WebRTC-потоком. При сигнале начала речи он сразу заглушает и приостанавливает вывод; Pipecat отменяет генерацию, а очередь отбрасывает старые пакеты. Завершение голоса не ждёт распознавания слов.

Сценарии, критерии, история, проверяемые переходы между этапами и отчёт общие для всех режимов. Прежний Inworld + локальный GLB сохранён для старых сессий; для него нужны ключ Inworld, включённый API и модель команды.

## Проверки

```bash
uv run --locked --extra voice pytest -q
npm --prefix frontend test
npm --prefix frontend run build
```

Команды автоматических тестов не вызывают платные API. В песочнице macOS нативный MLX может аварийно завершаться; проверяйте в обычном терминале.

Живые пробы 6 сентября: Tavus и Anam получили новый русский текст через голосовой движок, видео воспроизводилось, остановка и сохранение истории проверены. У Даниила проверены три реплики и итоговый отчёт. На синтетическом аудиопотоке сервер выдал прерывание до транскрипции. [Замеры и ограничения](artifacts/runs/09_selected_live_avatars/notes.md).

## Честные ограничения

- В коротких пробах от отправки текста до звука в видео: Tavus 4,1–5,3 с, Anam 4,3 с. Это не мгновенный ответ и не p95. Есть явный резерв без видео.
- Синтетическая проверка начала речи: 580 мс от первого входного пакета. Физический микрофон, акустика комнаты и человеческая оценка нового полного диалога ещё требуют проверки.
- Одно активное голосовое подключение на локальный стенд. По умолчанию до 180 секунд на подключение; после остановки можно подключиться снова с сохранением истории. Это защита бесплатных видеоквот, не лимит длины текстовой тренировки.
- Серверные ключи не гарантируют остаток квот. Голос и видео сверяйте в кабинетах провайдеров. Отмена не возвращает уже израсходованные токены или минуты.
- Роли без паролей, общая SQLite. Это локальный прототип, не публичный многопользовательский сервис. Нужны авторизация и изоляция данных перед публикацией.
- Оценка ИИ предварительная. Итог проверяет методист. Используйте только вымышленные учебные данные.
