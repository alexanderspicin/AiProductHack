# Локальный голос и аватар для защиты

Отдельный стенд: [открыть демо](http://127.0.0.1:8898). Основной тренажёр не меняет. Ключи не читает, внешние сервисы не вызывает. Интернет нужен при первоначальном получении зависимостей и моделей, не при показе.

Что показывать и говорить: [сценарий защиты и альтернативы](../../docs/OFFLINE_DEFENSE.md). Результаты реальных проверок: [run 17](../../artifacts/runs/17_offline_defense/notes.md).

## Запуск на текущем компьютере

Из корня `rehearsal`:

```sh
artifacts/private/07_avatar_graph/cpu_env/bin/python demos/offline/server.py
```

Открыть [локальную страницу](http://127.0.0.1:8898). Если она уже доступна, второй процесс не запускать. Остановка сервера: Ctrl+C в его терминале. Другой порт: `--port 8899`.

1. Дождаться сообщения «Готово».
2. Выбрать Piper или Silero. Нажать «Произнести».
3. Во время речи нажать «Остановить».
4. Изменить текст и повторить. Это новая генерация, не набор записанных ответов.

Повтор той же фразы тем же голосом помечается «Из кэша». До 500 символов; одновременно считается одна фраза. Кнопка останавливает воспроизведение и отбрасывает поздний результат, но не убивает уже начатый расчёт TTS. Кэш в памяти; WAV в игнорируемой папке `artifacts/private/17_offline_defense/clips`. Текст не записывается на диск, но остаётся слышимым в локальном WAV. Старые WAV этого стенда автоматически удаляются при успешных новых генерациях, сохраняются последние 24 и активный кэш. Не вводить личные данные для публичной защиты.

## Перенос на другой компьютер

Код Git сам по себе недостаточен. Нужны веса и заранее подготовленное лицо, они намеренно не включены в репозиторий.

| Что перенести или подготовить | Состав |
|---|---|
| Пакет лица | `manifest.json`, `audio_driver.onnx`, папки `base/` и `atlas/`; примерно 107 МБ в старом измерении |
| Piper Дмитрий | `ru_RU-dmitri-medium.onnx` и соседний файл `.onnx.json` |
| Silero, необязательно | `v5_5_ru.pt`, некоммерческая лицензия |
| Исходники | `demos/offline/` и `artifacts/runs/07_avatar_graph/` |

Новые окружения, не среда работающего тренажёра:

```sh
uv venv artifacts/private/offline-cpu --python 3.12
uv pip install --python artifacts/private/offline-cpu/bin/python -r artifacts/runs/07_avatar_graph/requirements-cpu.txt
uv venv artifacts/private/offline-tts --python 3.12
uv pip install --python artifacts/private/offline-tts/bin/python -r demos/offline/requirements-tts.txt
```

Пример структуры после разрешённого переноса:

```text
artifacts/private/offline-assets/
  package/manifest.json
  package/audio_driver.onnx
  package/base/000.jpg ...
  package/atlas/000.png ...
  piper/ru_RU-dmitri-medium.onnx
  piper/ru_RU-dmitri-medium.onnx.json
  silero/v5_5_ru.pt
```

```sh
artifacts/private/offline-cpu/bin/python demos/offline/server.py \
  --package artifacts/private/offline-assets/package \
  --tts-python artifacts/private/offline-tts/bin/python \
  --piper artifacts/private/offline-assets/piper/ru_RU-dmitri-medium.onnx \
  --silero artifacts/private/offline-assets/silero/v5_5_ru.pt
```

Отсутствующий Silero отключится в списке, Piper останется доступен. Если нет Torch, для Piper достаточно установить `piper-tts==1.7.0` и оставить Silero отсутствующим. Нужны совместимые с вашей системой колёса Python. Установка с нуля на другом компьютере в этом прогоне не проверялась; проверены существующие локальные окружения на Mac.

Голос: [официальный набор Piper](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/dmitri/medium). Silero: [репозиторий авторов](https://github.com/snakers4/silero-models). Загружать только доверенные веса: формат PyTorch package способен исполнять код. В стенде нет автоматических загрузок; Python-сетевые операции рабочего TTS-процесса запрещены.

Для нового лица нужен отдельный предрасчёт: [инструкция run 07](../../artifacts/runs/07_avatar_graph/QUICKSTART.md). Используемый пакет подготовлен из DH Live mini v1, а не из произвольного JPG. Путь «новая фотография до готового аватара» здесь не проверен. Предрасчёт можно выполнить на машине без интернета, если веса, входы и зависимости перенесены заранее. Эта GPU-машина не нужна онлайн во время показа.

## Если что-то не работает

| Симптом | Действие |
|---|---|
| `Prepared atlas missing` | Передать каталог с готовым `manifest.json` через `--package` |
| Голос недоступен | Проверить путь к весам и окружение `--tts-python`; для Piper нужен также `.onnx.json` |
| Нет звука | Проверить громкость, нажать кнопку мышью; скрытая вкладка останавливает речь |
| «Предыдущая фраза ещё рассчитывается» | Подождать завершения TTS, повторить; после 45 с процесс остановится по таймауту |
| Лицо загружается долго | Около 107 МБ локальных изображений; открыть страницу до выхода на сцену |

Сервер только на `127.0.0.1`. Его нельзя публиковать как многопользовательский сервис: нет авторизации, сессий и производственной очереди. Локальный HTTP нужен для связи браузера с Python; «без API» здесь означает без внешних облачных API.
