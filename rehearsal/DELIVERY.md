# Проверка передачи, 7 сентября 2026

Снимок текущего приложения размещён в отдельной папке рядом с исходным проектом команды. Старые исходники, тесты, модели и Docker-файлы не изменены. В общий README добавлена навигация. Основная рабочая копия автора не переключалась и не перезаписывалась.

## Проверено на копии для публикации

| Проверка | Результат |
|---|---|
| Серверные тесты `python -m pytest -q --tb=short` | 120 прошли |
| Интерфейсные тесты `npm --prefix frontend test` | 34 прошли, 11 файлов |
| Сборка `npm --prefix frontend run build` | успешна |
| Компиляция Python backend, scripts, demos | успешна |
| Расчёт дешёвых API | три сценария, пять контрольных утверждений прошли |
| Передаваемые исходники и документация | проверены на известные локальные ключи и распространённые форматы секретов |

Python-тесты использовали существующее окружение с зависимостями голоса, но исходники и тесты именно передаваемой копии. Зависимости интерфейса установлены заново через `npm ci`. Сначала офлайн-установка не нашла один пакет в кэше; обычная установка прошла. Первый запуск Python в песочнице macOS аварийно завершился при импорте MLX, повтор вне песочницы прошёл. Предупреждения об устаревающих интерфейсах Python и размере одного JS-фрагмента остаются; они не скрыты как ошибки приложения.

## Что не входит

Ключи, `.env.local`, базы диалогов, записи пользователей, приватные фото/видео, подготовленный атлас лица, веса моделей и каталоги зависимостей не публикуются. Веса для CPU-демо передаются отдельно после проверки прав; [инструкция](demos/offline/README.md). Публичные API используются только после настройки ключей и явного включения.

Автотесты подменяют внешние генераторы. Новых платных прогонов, оценки русского липсинка и повторного измерения задержки на реальном микрофоне в рамках передачи не было. Известные ограничения прототипа, включая роли без паролей, 180 секунд подключения и замечания аудита к поздним субтитрам, остаются в [README](README.md) и [аудите презентации](docs/PRESENTATION_AUDIT.md).
