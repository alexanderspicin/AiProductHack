# Выбранные живые персонажи

Основные пары: Cartesia Sergei + Tavus Daniel и Cartesia Tatiana + Anam Cara. Выбор пользователя после сравнения записанных образцов, не автоматический рейтинг. Новая версия использует эти пары в произвольном учебном диалоге.

## Подготовка

`uv sync --locked --extra voice`, `npm --prefix frontend ci`. Python 3.12. Для первого запуска нужен интернет: зависимости, словарь NLTK и модель Whisper. Для разговора интернет нужен OpenAI, Cartesia и выбранному видеосервису. Корпоративный GPU не требуется.

Модели Silero и Smart Turn поставляются с Pipecat. Локальный Whisper small работает на CPU/int8. Нативное исполнение macOS проверено; sandbox MLX может падать.

Словарь NLTK устанавливается до первого разговора:

```bash
uv run --locked --extra voice python -m nltk.downloader -d models/nltk_data punkt_tab
```

Если downloader отказывается работать через прокси, не отключайте его защиту глобально. Для фиксированного официального ресурса можно выполнить:

```bash
curl --fail --location --max-time 60 https://raw.githubusercontent.com/nltk/nltk_data/gh-pages/packages/tokenizers/punkt_tab.zip --output /tmp/rehearsal-punkt-tab.zip
mkdir -p models/nltk_data/tokenizers
unzip -q -n /tmp/rehearsal-punkt-tab.zip -d models/nltk_data/tokenizers
```

`models/` исключена из Git. `scripts.run_selected` устанавливает путь NLTK и проверяет наличие словаря до запуска сервера. При самостоятельном запуске uvicorn задайте `NLTK_DATA=models/nltk_data`.

## Ключи и запуск

Создайте `.env.local` по `.env.example`. Нужны `OPENAI_API_KEY`, `CARTESIA_API_KEY`, `TAVUS_API_KEY`, `ANAM_API_KEY`. Для одного персонажа достаточно его видеоключа и двух общих ключей. Для голоса без видео нужны только OpenAI и Cartesia. Старый 3D-режим отдельно использует Inworld.

```bash
uv run --locked --extra voice python -m scripts.check_voice --whisper
uv run --locked --extra voice python -m scripts.run_selected --enable-apis --port 8001 --seconds 180
```

Второй терминал:

```bash
npm --prefix frontend run dev
```

Открыть [тренажёр](http://127.0.0.1:5174/). При конфликте портов:

```bash
uv run --locked --extra voice python -m scripts.run_selected --enable-apis --port 8003 --seconds 180
REHEARSAL_API_TARGET=http://127.0.0.1:8003 npm --prefix frontend run dev -- --port 5176
```

Альтернативный адрес: [5176](http://127.0.0.1:5176/). Все серверы слушают только loopback, workers=1. Опциональные `--openai-env` и `--voice-env` читают нужные ключи из уже существующих файлов без копирования значений в проект. `TAVUS_PAL_ID` позволяет повторно использовать собственный Echo PAL; без него первый Tavus-запуск создаёт PAL, повторные подключения процесса используют его же.

## Управление разговором

Одна кнопка «Начать диалог» подключает видео и голос, бот начинает первым. Пишите в чат или говорите, переключать режим не нужно. Микрофон можно выключить до запуска либо во время разговора. При отказе браузера дать доступ к микрофону разговор продолжается через видео и текст; повторный запуск не нужен.

Кнопка «Перебить» и новое сообщение останавливают текущий ответ. «Ещё» открывает паузу соединения, резерв без видео и технические данные. «Завершить», затем «Получить разбор» закрывает соединение и запрашивает отчёт. Выход через кнопку «К тренировкам» также закрывает голос, сама история сохраняется.

## Контракт

| Запрос | Что делает |
| --- | --- |
| GET `/api/text/bootstrap?role=methodist` | Настройка показа, список пар, проверка наличия ключей без платных вызовов |
| PUT `/api/text/presentation` | `revision`, `voice_mode`, `avatar_profile`, `allow_audio_fallback`; модель и секреты здесь не принимаются |
| POST `/api/text/sessions` | Снимок сценария и настроек; видеоминуты не расходует |
| POST `/api/text/sessions/{id}/voice/prepare` | `request_id`, `audio_only`; создаёт одно ограниченное подключение |
| WebSocket из ответа prepare | Pipecat RTVI; краткоживущая lease в URL, не мастер-ключ |
| POST `/api/text/sessions/{id}/voice/stop` | `request_id` предотвращает отмену нового подключения старым запросом |
| POST `/api/text/sessions/{id}/end` | Разбор после остановки голоса |

Идентификаторы профилей: `tavus_sergei`, `anam_tatiana`, прежний `legacy_3d`. Старые сохранённые настройки без нового поля остаются legacy, а не мигрируют молча. Выбор нового персонажа меняет имя только в снимке новой тренировки, не исходный сценарий методиста.

## Поток и прерывание

Общая вводная и гибкий учёт целей описаны в [логике тренировки](ROLEPLAY.md). Новые сессии OpenAI учитывают цели вне порядка; старые сессии сохраняют последовательный режим. Голосовой движок и транспорт при этой правке не менялись.

1. Браузер передаёт микрофон только локальному серверу. Камера выключена.
2. Серверные Silero/Smart Turn управляют началом и окончанием хода; Whisper распознаёт русский текст.
3. OpenAI играет роль сценария. Переход этапа требует дословной цитаты участника. Примеры первых реплик последующих этапов не выдаются модели как готовые ответы.
4. Официальный CartesiaTTSService отдаёт PCM16 mono 24 kHz частями. Ожидания полного WAV нет.
5. RemoteAudioProcessor маркирует части поколением и контекстом. Браузер отправляет их в Tavus Echo или Anam audio passthrough. Один WebRTC-поток воспроизводит и звук, и видео, без дублирующего PCM-звука.
6. Начало речи немедленно вызывает локальные mute/pause и очистку очереди. Pipecat отменяет текущий ответ; видеосервис получает команду interrupt. Поздние пакеты старого контекста отбрасываются.
7. Перед новым ответом проверяется тишина удалённого потока. При неполученной остановке за 1,6 с соединение закрывается с предложением резерва, а не продолжает старую реплику.

Anam требует накопить часть аудио для первых кадров. Это отдельная задержка после LLM/TTS, не проблема языка сама по себе. Источники: [Anam custom TTS](https://anam.ai/docs/javascript-sdk/examples/custom-tts), [Tavus Echo](https://docs.tavus.io/sections/conversational-video-interface/echo-mode), [Tavus interrupt](https://docs.tavus.io/sections/event-schemas/conversation-interrupt), [Pipecat Cartesia](https://docs.pipecat.ai/server/services/tts/cartesia). Контракты дополнительно сверены с установленными SDK.

## Лимиты и отказы

- Один живой разговор на процесс. Повтор prepare с тем же идентификатором не создаёт вторую видеосессию. Отменённый запрос нельзя запустить задним числом.
- Незавершённое подключение освобождается через 40 с. Автоповторов внешних create-запросов нет.
- До 180 с на соединение, в служебных пробах 90 с. Tavus получает серверную максимальную длительность; Anam получает её в session token. Отключение, уход со страницы и остановка сервера освобождают ресурсы. При аварии клиента Anam дополнительно ограничен серверной длительностью.
- Если остановка не подтверждена, интерфейс предлагает повторить отключение; новое соединение не запускается молча.
- Ошибка видео не стирает стенограмму. «Разговор без видео» сохраняет выбранный голос; переписка доступна после отключения. Методист может запретить голосовой резерв.
- Ключи не доказывают доступность API, квот и моделей. Реальная проверка происходит при подключении. Бесплатные тарифы и их ограничения смотрите в кабинетах перед массовым тестом. Подписок приложение не покупает.
- Токены и оценка стоимости LLM есть в админке. TTS/видеоминуты сверяются в кабинетах, не выдаются за точный денежный счёт приложения.

## Приёмка человеком

В наушниках, отдельно для каждого персонажа:

1. Произнесите новую фразу с русскими именами и числами. Проверьте произношение и губы.
2. Перебейте в середине ответа. Звук должен остановиться до распознавания всей вашей фразы; старые слова не должны вернуться.
3. Сделайте короткую паузу внутри предложения. Проверьте, не забирает ли бот ход преждевременно.
4. Задайте уточнение. Ответ должен учитывать его, а не воспроизводить шаблон этапа.
5. Отключитесь и продолжите текстом. Завершите, откройте разбор, проверьте цитаты.
6. При медленном видео повторите тот же разговор кнопкой «Разговор без видео». Сравнивайте отдельно скорость и качество лица.

Автоматические тесты доказывают контракты и отмену, не естественность. Начальная синтетическая проверка дала VAD-событие за 580 мс от первого пакета, до слов; это не замер физического микрофона. Полный новый диалог и акустическое эхо остаются ручной приёмкой.
