# Проверка варианта команды

Гипотеза: существующий тренировочный интерфейс можно подключить к настоящим модулям команды, сохранив серверные VAD/Smart Turn, голос, артикуляцию и отчёты. Проверяется интеграция; сравнение качества провайдеров не проводится.

## Команды

Из `rehearsal-team`:

```sh
python -m pytest -q
npm --prefix frontend test
npm --prefix frontend run build
uv sync --locked --extra voice --dry-run
python -m scripts.check_team --audio sample.wav
python -m scripts.run_team --enable-apis
python -m scripts.probe_team --audio sample.wav --output artifacts/private/probe.json
```

Тесты и живой запуск выполнены в уже установленном Python 3.12 окружении с Pipecat 1.8.1. Lock-файл разрешён успешно; dry-run проверил план установки 107 пакетов. Полная повторная установка в пустое окружение не выполнялась. Автотесты заменяют внешние генераторы заглушками, проверка моделей и живая проба используют настоящие фабрики команды. На macOS импорт MLX требует обычного процесса с доступом к устройству, хотя Whisper запускается на CPU.

## Результаты и ошибки

1. Бесплатные тесты: 96 серверных, включая происхождение импортов, сценарные снимки, цитаты, остановку, конкурентный запрос, протокол и алгоритмы артикуляции; 26 интерфейсных, включая StrictMode, единый Pipecat-контекст, поздние субтитры, микрофон, повтор остановки и бесплатный предпросмотр. Сборка прошла. Vite предупреждает о крупном лениво загружаемом пакете голоса/Three.js: 1,073 МБ, 280 КБ gzip.
2. CPU: Whisper загрузился за 952 мс; восьмисекундная синтетическая фраза распознана за 2244 мс. VAD прошёл состояния QUIET/STARTING/SPEAKING/STOPPING. Smart Turn вернул INCOMPLETE за 55 мс на обрезанном фрагменте. Это не замер точности модели.
3. Первая живая проба: Inworld выдал звук, ручная отмена дошла за 6 мс. OpenAI отверг function tools при выбранном reasoning. В адаптере задан reasoning_effort=none, фабрика команды не изменялась.
4. Вторая проба: Inworld WebSocket получил Connection refused, звук отсутствовал. Сессия остановлена, пустой отчёт без баллов сохранён. Проверка нового авторизованного WebSocket без синтеза затем прошла.
5. Третья проба прошла: 8,84 с полученного PCM, 438 событий визем, 13 различных форм рта, 19 событий TTS-текста, три сохранённых реплики, готовый отчёт. Ручное прерывание 4 мс до события; VAD 680 мс от начала подачи файла, до первой расшифровки ещё 1548 мс. Текст до первого аудио ответа 6408 мс. Остановка и завершение вернули HTTP 200.
6. В браузере проверены роли, выбор формата, вводная, план, GLB и поле ввода. При 1280×720 переполнения нет, поле ввода видно. Предпросмотр не включает микрофон и API.

В сессии распознавание разделило синтетический фрагмент на две реплики. Нельзя переносить полученный результат на любые русские фразы, шум и устройства. Успешное получение визем не заменяет оценку синхронности человеком.

## Расход и воспроизводимость

Пять запросов OpenAI с известным usage: 8202 токена, оценка журнала $0,00206402 по сохранённым тарифам. Есть прерванные/неуспешные запросы без полного usage. Синтез Inworld отдельно не тарифицирован в журнале, поэтому общая фактическая стоимость не заявляется. Видео-API не вызывались. Покупок и пополнений не было.

Микрофон и камера пользователя не включались. Передавалась только ранее созданная синтетическая речь и вымышленные сценарии. Сырые WAV, JSON с полной стенограммой и локальные базы сохранены в игнорируемой private-папке, в Git не передаются.

Решение: keep для отдельной демонстрационной версии на бэкенде команды. Скоростные цели слайдов и человеческая оценка губ остаются inconclusive. Применимость измерений ограничена одной машиной и одной успешной сессией; провалы предыдущих запусков не исключены из журнала.
