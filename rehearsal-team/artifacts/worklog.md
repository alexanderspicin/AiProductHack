# Журнал интеграции, 7 сентября 2026

Режим TASK2_AI. Задача: отдельное приложение на настоящем бэкенде команды, совместимое с технологическим составом исходной презентации. Срок: текущая передача перед защитой; первоначальный тайм-бокс 90 минут, продлён для диагностики двух ошибок живого теста. Артефакты: код, тесты, запуск, соответствие слайдам, две ссылки в исходном репозитории.

Независимая оценка: смена вывески API-версии не решает запрос. Выбран прямой импорт соседнего `backend/app`, отдельные порты и SQLite. Исходные backend/frontend и папка API-версии оставлены без изменений. Презентация описывает гибрид с OpenAI и Inworld; полностью автономный вариант не заявляется.

Сначала собран бесплатный сквозной результат с тестовыми ответами. Затем проверены происхождение импортов, настоящие CPU-модели и одна ограниченная голосовая сессия. Детали, ошибки и замеры: [протокол](runs/22_team_pipeline/notes.md).

Тесты выявили различие конструктора RunnerArguments, живой запуск выявил необходимость reasoning_effort=none для function tools выбранной LLM. Ручная отмена дополнена встроенным rtvi.interrupt_bot: одной очистки очереди недостаточно для прекращения генерации.

В браузере проверены кабинет методиста, выбор формата, вводная участника и 3D-предпросмотр без микрофона. Проверен размер 1280×720: сцена 896×473 px, поле текста полностью на экране, горизонтального переполнения нет. Подключение физического микрофона и оценка губ человеком не выполнялись.

Перед публикацией: тесты, сборка, контроль списка изменений, поиск секретов и частных путей в новых файлах. Сырые записи, ключи, базы и окружения исключены. Прежние результаты не удаляются.

Финальный прогон: 96 серверных и 26 интерфейсных тестов, сборка успешна. В 92 подготовленных файлах секреты и абсолютные частные пути не найдены. Проверка списка изменений исходных backend/frontend и API-версии не показала правок. Публикация подготовлена отдельным коммитом поверх master, без переписывания истории.
