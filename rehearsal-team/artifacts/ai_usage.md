# Вклад AI

Запрос владельца: собрать отдельный вариант на реальном бэкенде команды по исходной презентации, проверить и опубликовать рядом с API-версией.

AI сопоставил слайды с исходниками, выделил интерфейс и тренировочный слой, подключил исходные фабрики Pipecat и VisemeProcessor, добавил управление сессией, тесты, запуск и документацию. Речевые алгоритмы команды не переписывались. UI сохранён по принципам Impeccable; добавлен предпросмотр без микрофона и защита от повторного подключения до остановки предыдущего.

Проверка предложений: автоматические тесты, реальное распознавание синтетической русской записи, ограниченный разговор с OpenAI/Inworld, просмотр UI и 3D в браузере. Найденные ошибки: неверный параметр конструктора Pipecat, несовместимый reasoning с function tools, временный отказ Inworld. Последняя живая проба успешна; неудачные пробы включены в журнал.

Человек должен подтвердить естественность голоса, точность губ и перебивание через физический микрофон. Задержки из презентации не объявлены достигнутыми. Отчёт LLM требует проверки методиста.
