# Репетиция: версия на бэкенде команды

Кабинеты участника, методиста и администратора, сценарии, диалог и отчёт поверх исходного голосового движка AiProductHack. Архитектура соответствует технологическому составу исходной презентации: Pipecat, серверные Silero VAD и Smart Turn v3, faster-whisper, OpenAI, Inworld и локальный Three.js/GLB.

[API-версия с Cartesia и Tavus/Anam](../rehearsal/README.md) сохранена отдельно, без изменений. [Исходный голосовой прототип команды](../README.md#backend) тоже сохранён.

Это локальный прототип для защиты. OpenAI и Inworld требуют интернета и ключей. Обещанные в презентации задержки пока не подтверждены; фактические результаты и оставшиеся расхождения указаны в [DEFENSE.md](DEFENSE.md).

## Запуск

Нужен полный клон AiProductHack: новая версия импортирует соседний `backend/app` и берёт GLB из соседнего `frontend`. Копирование только этой папки не подходит.

Python 3.12, uv, Node.js 22.18 или новее. Команды выполнять из `rehearsal-team`:

```sh
uv sync --locked --extra voice
npm --prefix frontend ci
cp .env.example .env.local
```

В `.env.local` заполнить `OPENAI_API_KEY` и `INWORLD_API_KEY`. Для Inworld нужен Runtime API Key в формате Basic-auth, без добавленного префикса `Basic `. Голос по умолчанию `Svetlana`. Ключи остаются на сервере; не добавляйте их в Git.

Подготовить локальные модели до демонстрации:

```sh
uv run --locked --extra voice python -m nltk.downloader -d models/nltk_data punkt_tab
uv run --locked --extra voice python -m scripts.check_team
```

Первый запуск скачивает веса. На CPU используются Whisper small/int8, Silero и ONNX Smart Turn. Это проверка загрузки; первая голосовая сессия дополнительно создаёт экземпляры моделей и соединение с Inworld.

Первый терминал:

```sh
uv run --locked --extra voice python -m scripts.run_team --enable-apis
```

Второй терминал, также из `rehearsal-team`:

```sh
npm --prefix frontend run dev
```

Открыть [http://127.0.0.1:5177/](http://127.0.0.1:5177/). Сервер слушает `127.0.0.1:8004`. Эти порты не пересекаются с API-версией. GLB автоматически копируется из исходного проекта перед запуском и сборкой фронтенда.

## Демо за несколько минут

1. «Открыть как: Методист». Открыть сценарий, показать ситуацию, характер персонажа, цели и критерии. Черновик можно сохранить отдельно от публикации.
2. «Персонаж тренировки». Показать выбранный формат «Голос, текст и 3D-персонаж» и состав движка.
3. «Открыть как: Участник». Выбрать «Клиент ждёт решения». Этот сценарий подходит к женскому GLB и голосу Svetlana. Прочитать вводную, дать согласия и начать тренировку.
4. «Посмотреть персонажа без микрофона» показывает локальный 3D без вызовов API. «Начать диалог» включает микрофон и голосовую сессию; персонаж произносит первую реплику.
5. Сказать: «Понимаю, что ждать неприятно. На каком шаге появляется ошибка?» Во время ответа начать говорить снова. Проверить, что речь и рот останавливаются до появления расшифровки. Для проверки рекомендуется гарнитура.
6. Выключить микрофон, отправить сообщение в чат. Пока голосовая сессия открыта, текст проходит через тот же Pipecat-контекст и озвучивается.
7. «Завершить», затем «Получить разбор». Сначала останавливается голос, затем строится отчёт по сохранённой стенограмме. Методист видит цитаты, может проверить выводы и оставить комментарий.

«Приостановить» закрывает голосовое соединение, сохраняя историю. Повторный запуск продолжает тот же сценарий. При ошибке остановки новое подключение блокируется до подтверждения отключения.

## Без ключей

Интерфейс, редактор сценариев, история и предпросмотр GLB доступны локально. Для разговора без API выберите у администратора демонстрационные ответы, а у методиста «Только переписка». Это явно обозначенные заготовки для проверки интерфейса, не локальная LLM. Живой голос и оценка LLM без ключей не работают.

## Что переиспользовано

| Компонент | Реальный исходник команды |
|---|---|
| Whisper | `../backend/app/pipeline/stt.py` |
| Silero + Smart Turn | `../backend/app/pipeline/turn_detection.py` |
| OpenAI и Inworld | `../backend/app/pipeline/llm.py`, `tts.py` |
| WebSocket/PCM | `../backend/app/pipeline/transport.py` |
| Артикуляция и таймлайн слов | `../backend/app/avatar/viseme_processor.py`, `viseme_text.py`, `viseme_analysis.py` |
| GLB | `../frontend/public/models/avatar.glb` |

`backend/text_app/team_pipeline.py` связывает эти фабрики с тренировкой: роль персонажа, история, инструмент `advance_stage`, запись реплик, учёт токенов. Порядок восьми процессоров сохранён. В голосовой цепочке нет клиентского VAD, самописного распознавателя или видеогенератора по API.

Браузер использует официальный Pipecat WebSocketTransport и его плеер. Three.js получает события исходного VisemeProcessor; после прерывания отбрасываются старые виземы. Подробности интеграции и отличия от слайдов: [DEFENSE.md](DEFENSE.md).

## Проверки

```sh
uv run --locked --extra voice pytest -q
npm --prefix frontend test
npm --prefix frontend run build
```

Проверка настоящего распознавания без платных API, на собственной синтетической WAV 16 кГц, mono, PCM16:

```sh
uv run --locked --extra voice python -m scripts.check_team --audio sample.wav
```

Одна ограниченная живая проба с настроенным сервером, OpenAI и Inworld. Команда расходует API; не запускать циклом:

```sh
uv run --locked --extra voice python -m scripts.probe_team \
  --audio sample.wav --output artifacts/private/my-live-probe.json
```

Она передаёт только первые четыре секунды указанной записи, не включает микрофон и не обращается к видео-API. Максимальное ожидание голосовой части 55 секунд. Сырые результаты и звук сохраняются только в игнорируемой папке. [Протокол выполненных проверок](artifacts/runs/22_team_pipeline/notes.md).

## Ограничения

- Один активный голосовой разговор на локальный сервер, один процесс Uvicorn. Роли без паролей; для интернета нужны авторизация, изоляция данных, HTTPS и проверка доступа.
- Сценарии и стенограммы хранятся в SQLite под `artifacts/`; это локальные данные, они не публикуются. Ключи и модели также исключены из Git.
- LLM-наблюдения целей предварительные. Балл требует проверяемой цитаты участника, кадровые решения оставлены человеку.
- Полной автономной LLM и кэша произвольного TTS нет. При сбое API доступны сохранённая история и ручной повтор. Ошибка провайдера может завершить голосовую сессию.
- В текущем GLB один женский персонаж. Имя, роль и род задаются сценарием; мужской сценарий требует согласованных модели и голоса. Автоматической замены GLB по полу нет. Коммерческие права на демонстрационный GLB отдельно не подтверждены; см. исходный README.
- Статистика считает полученные токены OpenAI и оценочную стоимость по сохранённому тарифу. Прерванные запросы без usage остаются неизвестными. Счёт Inworld туда не входит.
